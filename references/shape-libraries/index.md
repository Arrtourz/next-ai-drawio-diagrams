## Catalog integrity note

This package includes 29 Draw.io catalog files and one Material icon catalog. An older source index named four additional catalogs (`arista`, `digitalocean`, `eip`, and `un-ocha-icons`) but did not contain those files; the broken entries are intentionally omitted here. Some specialized catalogs are concise usage references rather than exhaustive Draw.io inventories. Search results describe the identifiers actually packaged with this skill.
